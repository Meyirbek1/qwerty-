# aqiqat.ai — Жасанды интеллект көмегімен жалған ақпарат анықтау жүйесі
Запуск (Node.js 18+, **npm install не нужен**):
1. `cp .env.example .env` (Windows: скопируйте файл и назовите `.env`), впишите `GEMINI_API_KEY` (aistudio.google.com) или оставьте `AI_PROVIDER=demo`
2. `npm start` → http://localhost:3000
3. Тесты: `npm test`
Если ИИ недоступен или лимит исчерпан — автоматически включается демо-режим по правилам.

## Аккаунттар
Талдау тек тіркелген пайдаланушыларға ашық. Пайдаланушылар `data/users.json` ішінде (құпиясөз scrypt-хэшпен), сессия — HttpOnly cookie.
`data/` және `.env` файлдарын архивке қоспаңыз.
